# 🌐 JSON & XML Viewer

A lightweight, fast, and user-friendly web tool to view, format, and explore **JSON** and **XML** data in multiple modes.

Built with pure **HTML + CSS + Vanilla JavaScript** — no frameworks, no dependencies.

---

## ✨ Features

✅ Supports both **JSON and XML**  
✅ Clean Raw Data editor  
✅ Pretty Format view  
✅ Interactive Tree view 🌳  
✅ Expand / Collapse nodes  
✅ Right-click context menu (Expand / Collapse)  
✅ Visual guide lines for nested objects  
✅ Color-coded data types  
✅ Developer Info panel 👨‍💻  
✅ Lightweight & fast  
✅ Works offline  
✅ GitHub Pages compatible 🚀

## 🚀 Getting Started


---

## 🌐 Deploy on GitHub Pages

1. Push the project to GitHub
2. Go to **Repository → Settings → Pages**
3. Select branch: `main`
4. Save

Your tool will be live at:

```
https://<username>.github.io/<repository-name>/
```

## 🖱️ How to Use

### 🔄 Switch Viewer Mode

Click **JSON Viewer** or **XML Viewer** at the top.

Switching mode clears existing data.

---

### 📑 Tabs

| Tab | Description |
|------|-------------|
